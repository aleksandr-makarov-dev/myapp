# Грамматика Suomen mestari

В [разделе «Грамматика»](docs/grammar/index.md) есть ссылка на [упражнения](docs/exercises.md).
Изображения из Suomen mestari хранятся в `docs/assets/grammar/` и сгруппированы по темам.

Изображения извлечены из предоставленных PDF в исходном разрешении.
Разные темы на одной странице разделены обрезкой. PNG сохранены без потерь. Для более чёткого отображения применено лёгкое
усиление резкости без масштабирования, ретуши и дорисовки текста.

Проверка: `zensical build --clean`. Просмотр: `zensical serve`.
