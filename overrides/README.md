# Встроенный Quizlet в Markdown

Поставьте метку отдельной строкой, с пустыми строками до и после:

```markdown
<!-- quizlet: 1228543353 match -->
```

Первый параметр — числовой ID публичного набора Quizlet, второй — режим:
`flashcards`, `learn`, `test`, `match` или `spell`.
Если режим не указан, используется `flashcards`:

```markdown
<!-- quizlet: 1228543353 -->
```

В любом месте страницы можно вставить несколько независимых наборов:

```markdown
## Слова

<!-- quizlet: 1228543353 flashcards -->

## Практика

<!-- quizlet: 1228543162 learn -->
```

Метка при сборке становится стандартным iframe Quizlet с адресом
`https://quizlet.com/ID/РЕЖИМ/embed`. Интерфейс, игры и проверку ответов
полностью предоставляет Quizlet. Собственного тренажёра и JavaScript-компонента нет.
Режим выбирается в Markdown; доступность игры определяется самим Quizlet.
YAML-поля `template` и `quizlet_url` не нужны.
Полную ссылку вместо числового ID в метку передавать не нужно.

Шаблон `main.html` разбирает метки, а `partials/quizlet.html` выводит iframe.
Переменные внутри include не изменяют фрагменты исходной страницы, поэтому части
адреса вида `-->quizlet.com-->…` больше не появляются в тексте.

## Подключение новых наборов

Добавьте метку с числовым ID набора и режимом. Набор должен быть публичным.

## Видимость таблиц

Восстановлены прежние кнопки: «Всё», «Финский», «Перевод». Выбор сохраняется
между страницами. Встроенные игры Quizlet этими кнопками не управляются.
