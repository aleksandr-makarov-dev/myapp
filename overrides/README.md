# Quizlet

Добавляйте наборы прямо в текст любой Markdown-страницы:

```markdown
## Карточки по теме

<!-- quizlet: https://quizlet.com/1228543162/flashcards/embed?i=53ndi1&x=1jj1 -->

Здесь можно написать пояснение или добавить другой раздел.

<!-- quizlet: https://quizlet.com/1228543353/flashcards/embed -->
```

Количество блоков не ограничено. Каждый набор появится на месте своей метки.
Поля `quizlet_url` и `template` в YAML-заголовке не нужны.
Размещайте каждую метку отдельной строкой вне блоков кода.

Поддерживаются полные ссылки на набор с числовым ID, в том числе с языковым
префиксом: https://quizlet.com/ru/1228543162/название-flash-cards/.
Можно вставить URL из src кода встраивания Quizlet. Режимы Match и Learn
преобразуются во Flashcards. Параметры после ? сохраняются.
Для короткой ссылки quizlet.com/_... сначала откройте набор и скопируйте полный адрес.
Вставляйте только URL, без кавычек и без кода iframe.

Каждый блок содержит заголовок «Практика в Quizlet», карточки высотой 720 пикселей
и ссылку для открытия в отдельной вкладке. Карточки загружаются по мере прокрутки.
Пустая метка <!-- quizlet: --> ничего не отображает.

Обработка меток находится в main.html, общий компонент — в partials/quizlet.html.
Шаблон finnish.html оставлен для совместимости.
После изменений пересоберите сайт командой zensical build или используйте
автоматическое обновление zensical serve.
