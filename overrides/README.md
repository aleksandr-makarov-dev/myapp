# Quizlet

В начале каждой тематической страницы уже есть настройки:

```yaml
template: finnish.html
quizlet_url: ""
```

Вставьте ссылку на свой набор в `quizlet_url`:

```yaml
quizlet_url: "https://quizlet.com/1227510462/flashcards/embed?i=53ndi1&x=1jj1"
```

Можно использовать и полную ссылку на набор с числовым ID, например
`https://quizlet.com/1227510462/название-набора-flash-cards/`.
Компонент выберет режим Flashcards. Поддерживаются ссылки с языковым префиксом,
например `https://quizlet.com/ru/1227510462/название-набора-flash-cards/`.

Поле принимает URL, а не весь код `<iframe>`. Для короткой ссылки вида
`quizlet.com/_...` откройте набор и скопируйте полный адрес или значение `src`
из кода встраивания Quizlet.

При пустом `quizlet_url` блок скрыт. Когда ссылка задана, перед разделом «Источники»
появляются карточки высотой 720 пикселей и ссылка для открытия в отдельной вкладке.

Общий компонент находится в `partials/quizlet.html` и подключается шаблоном
`finnish.html`. Для отображения новой ссылки пересоберите сайт командой
`zensical build` или используйте автоматическое обновление в `zensical serve`.

Позицию блока задаёт метка `<!-- quizlet -->` в Markdown.
Ссылки на режимы Match и Learn также открываются как Flashcards.
