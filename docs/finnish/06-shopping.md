## Глагольное управление {#useful-structures}

Только особые падежи и конструкции для значений этой темы. Для partitiivi приведена типичная модель.

| Глагол | Управление | Пример |
| --- | --- | --- |
| **maksaa** | objekti; mistä? + kenelle?; millä? (способ оплаты) | Voinko maksaa kortilla? |
| **etsiä** | ketä? / mitä? (partitiivi); mistä? (место поиска) | Etsin lämmintä takkia. |
| **löytää** | mistä? (место находки в форме «откуда») | Löysin takin kaupasta. |
| **mahtua** | mihin? (illatiivi) | Nämä kengät eivät mahdu jalkaan. |
| **vaihtaa** | mihin? (на что обменять; illatiivi) | Vaihdan paidan pienempään kokoon. |
| **verrata** | mitä? + mihin? (partitiivi + illatiivi); объекты сравнения: verrata hintoja | Vertaan hintoja ennen ostamista. |
| **puuttua** | mistä? (elatiivi, отсутствовать в чём-то) | Paketista puuttuu yksi osa. |
