## Глагольное управление {#useful-structures}

Только особые падежи и конструкции для значений этой темы. Для partitiivi приведена типичная модель.

| Глагол | Управление | Пример |
| --- | --- | --- |
| **oppia** | objekti / mitä?; MA-инфинитив в illatiivi: oppia lukemaan | Opin joka päivä uusia sanoja. |
| **opettaa** | mitä? + kenelle?; ketä? + MA-инфинитив: opettaa lasta lukemaan | Hän opettaa suomea aikuisille. |
| **onnistua** | missä? (inessiivi); MA-инфинитив: onnistua tekemään | Tehtävä onnistui hyvin. |
| **soittaa** | kenelle? (звонить); mitä? (partitiivi, играть на инструменте) | Soitan sinulle tauolla. |
| **ilmoittautua** | mihin? (на что: ilmoittautua kurssille); kenelle? (у кого зарегистрироваться) | Ilmoittaudun suomen kurssille. |
| **käyttää** | mitä? (partitiivi); mihin? (назначение) | Voinko käyttää tätä tietokonetta? |
