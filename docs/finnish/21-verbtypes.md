# 21. Глаголы по типам {#verbtypes}

**140 глаголов · типы 1–6.**

Полный список из разделов «Some other common type … verbs» статьи Uusi kielemme. Глаголы сгруппированы по типам; внутри каждого типа сохранён порядок источника. Часть слов встречается и в бытовых темах.

В скобках после каждого инфинитива указан тип спряжения: например, `jutella (3)`. Переводы слов и примеров даны на английском.
