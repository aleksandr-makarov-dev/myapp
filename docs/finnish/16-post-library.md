# 16. Почта и библиотека {#post-and-library}

Отправить посылку, получить помощь у сотрудника и взять книгу в библиотеке.

**50 слов и выражений · 15 глаголов · уровень A1–A2.**

| Слово        | Перевод               | Пример                        | Перевод примера                         |
| ------------ | --------------------- | ----------------------------- | --------------------------------------- |

| postittaa    | to post, send by post | Postitan kirjeen huomenna.    | I will post the letter tomorrow.        |
| jonottaa     | to queue              | Jonotan postissa.             | I am queuing at the post office.        |

## Глагольное управление {#useful-structures}

Только особые падежи и конструкции для значений этой темы. Для partitiivi приведена типичная модель.

| Глагол | Управление | Пример |
| --- | --- | --- |
| **lainata** | objekti + mistä? / keneltä? (взять взаймы); kenelle? (дать взаймы) | Lainaan kaksi kirjaa. |
| **neuvoa** | objekti / ketä?; mihin? (куда направить); MA-инфинитив: neuvoa tekemään | Voitko neuvoa minua? |
| **suositella** | mitä? (partitiivi) + kenelle? (allatiivi) | Voitko suositella helppoa kirjaa? |
